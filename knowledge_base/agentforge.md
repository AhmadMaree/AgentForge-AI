# AgentForge

AgentForge is a Python AI agent framework.

AgentForge supports Gemini as a language model provider.

Its ReAct agent selects tools, executes them,
observes results, and produces a final answer.

AgentForge includes working memory, episodic memory,
and semantic memory.

Episodic memory uses SQLite and Qdrant.

Semantic memory combines vector retrieval with
Neo4j knowledge graph relationships.
